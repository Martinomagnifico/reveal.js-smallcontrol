What does it do?

Smallcontrol makes the controls (the navigation arrows in the corner there) smaller. Just the vertical ones.

Colors in Reveal

Standard Reveal themes give the arrows the same color that it uses for links. In this theme it is very blue.

Reveal also defines what color the controls should be on slides where the user has set another background color: If that background color is very dark, the controls become white, and if it is very light, the controls become black.

Colors in Smallcontrol

Smallcontrol keeps the color your theme gives the arrows, the color of its links.

Only on slides that contrast the theme does it do something different: there the arrows get the color of the text on that slide, instead of plain black or white, like Reveal normally does. For an example, see light slide in this deck.

Your own colors

If you still want other colors, set them for regular slides and/or for slides that contrast the theme:

Reveal.initialize({
	//...
	smallcontrol: {
		color: 'orange',
		inversecolor: 'darkred'
	},
	plugins: [ Smallcontrol ]
})

Scaling

Reveal draws its controls at the same size, however large it draws the slides. On a big screen they end up small and far away.

With autoscale, they grow along with the slides, up to twice their size, or what you set with maxscale. This deck has it on: make the window larger to see it.

Reveal.initialize({
	//...
	smallcontrol: {
		autoscale: true,
		maxscale: 2
	},
	plugins: [ Smallcontrol ]
})

The stylesheet

Smallcontrol loads its own stylesheet. If you import it yourself, set csspath: false, or point csspath at your own file.

import Smallcontrol from 'reveal.js-smallcontrol';
import 'reveal.js-smallcontrol/smallcontrol.css';
