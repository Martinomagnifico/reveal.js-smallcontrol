A placeholder in the bar

Put a div with the class controls in the bar, and Simplemenu moves Reveal’s controls into it. Smallcontrol does the rest.

Reveal.initialize({
	simplemenu: {
		barhtml: {
			header: "<nav class='menubar'>"
				+ "<div class='padbox'></div>"
				+ "<ul class='menu'></ul>"
				+ "<div class='padbox'>"
				+ "<div class='controls'></div>"
				+ "</div>"
				+ "</nav>"
		}
	},
	plugins: [ Simplemenu, Smallcontrol ]
});

That’s it!
